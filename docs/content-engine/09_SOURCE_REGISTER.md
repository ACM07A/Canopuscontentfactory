# Editorial source policy

For publishable medical content, prioritize:
1. clinical guideline / recognized society;
2. government;
3. regulator/accreditation;
4. official hospital;
5. official clinician profile;
6. peer-reviewed evidence;
7. high-quality secondary source only when needed.

Every volatile fact should store:
- source URL;
- retrieved/verified date;
- expiry/revalidation date;
- reviewer;
- verification state.
